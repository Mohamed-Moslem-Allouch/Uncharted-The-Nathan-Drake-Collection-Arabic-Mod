# UNCHARTED: The Nathan Drake Collection - Full Arabic Localization Mod

![Arabic Localization](assets/hero.png)

## 📖 About

Full Arabic Localization Mod for **UNCHARTED: The Nathan Drake Collection** (PC Port Version).

After reverse-engineering and unpacking the original game engine and archives, I am pleased to present a complete and comprehensive Arabic localization covering the entire trilogy:
- **UNCHARTED: Drake's Fortune**
- **UNCHARTED 2: Among Thieves**
- **UNCHARTED 3: Drake's Deception**

Featuring high-definition native Arabic typography, full Right-to-Left (RTL) text shaping, and 100% complete dialogue, subtitles, and user interface translation.

## 🛠️ Installation

### English

1. Copy the `Game` folder and paste it directly into your main **UNCHARTED: The Nathan Drake Collection** root directory (where the original `Game` folder is located).
2. Accept replacing existing files when prompted.
3. Launch the game, go to **Options → Language**, and choose `العربية` (Français slot) for Text and `تشغيل` (`On`) for Subtitles.
4. Enjoy the entire trilogy in pure native Arabic!

### العربية

1. انسخ مجلد `Game` والصقه مباشرةً في المجلد الرئيسي للعبة **UNCHARTED: The Nathan Drake Collection** (حيث يوجد مجلد `Game` الأصلي).
2. وافق على استبدال الملفات الموجودة عند ظهور رسالة التأكيد.
3. شغّل اللعبة، ثم اذهب إلى **خيارات (Options) → اللغة (Language)**، واختر `العربية` (خانة اللغة الفرنسية) للنصوص و `تشغيل` للترجمة.
4. استمتع بالثلاثية باللغة العربية الأصلية الخالصة!
